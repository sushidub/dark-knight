# Dark Knight

A VSCode theme for dark knights.

## Misc
Dark Knight was completely inspired by the VSCode [Night Owl](https://marketplace.visualstudio.com/items?itemName=sdras.night-owl) theme and its author [Sarah Drasner](https://marketplace.visualstudio.com/publishers/sdras). Please check out Sarah's other work, themes, and the [original accessible Night Owl theme](https://github.com/sdras/night-owl-vscode-theme) on her [Github](https://github.com/sdras/).

## Install options
#### VSCode IDE
1. Download the extension package [dark-knight-1.0.0.vsix](dark-knight-1.0.0.vsix).
2. From the Extensions view in VS Code:
3. Select Views and More Actions...
4. Select Install from VSIX...
#### VSCode cli
```bash
code --install-extension dark-knight-1.0.0.vsix
```
